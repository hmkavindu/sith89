## Implementation Details
- **Base System**: Extend existing Abhidhamma tool (89 cittas, 52 chaithasikas)
- **Three Poisons Framework**:
  - Raga (Lobha): Attachment, desire, greed
  - Dvesha: Aversion, hatred, anger
  - Moha: Ignorance, delusion, confusion
- **Analysis Flow**: Thought input → Classification → Interactive analysis → Educational content → Guidance
- **Data Sources**: Excel file data + Tripitaka teachings
- **User Experience**: Progressive disclosure, interactive exploration, personalized guidance
