# අභිධර්මය - චිත්ත චෛතසික මෙවලම (Buddhist Meditation Tool)

A comprehensive web application for studying Buddhist meditation and consciousness states based on the Abhidhamma teachings.

## Features

### 🌐 Bilingual Support
- **Sinhala and English** language support
- **Language switcher** button in the top navigation
- **Automatic translation** of all content including:
  - Navigation menu items
  - Section titles and descriptions
  - Table headers and data
  - Search placeholders and filters
  - Comparison tool interface
- **Persistent language preference** saved in browser

### 🏠 Home Page
- Beautiful hero section with Buddhist blessings
- Introduction to the tool and its purpose
- Quick navigation to main features

### 📊 Main Data Table
- Complete list of all consciousness states (Cittas)
- Search functionality to find specific states
- Category filtering (කුසල්, අකුසල්, අභ්‍යාකත, ලෝකෝත්තර)
- Interactive table with hover effects

### 🔍 Consciousness Categories
- **කුසල් චිත්ත** (Wholesome Consciousness) - 89 states
- **අකුසල් චිත්ත** (Unwholesome Consciousness) - 12 states  
- **අභ්‍යාකත චිත්ත** (Indeterminate Consciousness) - 21 states
- **චෛතසික 52** (Mental Factors) - 52 factors

### 📋 Chaithasika Analysis
- Detailed explanations of mental factors
- Categories: සාධාරණ, පක්ෂික, අකුසල්
- Interactive cards with descriptions

### ⚖️ Comparison Tool
- Select up to 5 consciousness states
- Compare associated mental factors
- Visual comparison table with checkmarks
- Real-time updates

## Technical Features

- **Responsive Design**: Works on desktop, tablet, and mobile
- **Sinhala Language Support**: Full Unicode support for Sinhala text
- **Modern UI**: Clean, professional design with smooth animations
- **Interactive Elements**: Hover effects, smooth scrolling, mobile menu
- **Search & Filter**: Real-time search and category filtering
- **Keyboard Shortcuts**: Ctrl+F for search, Escape to clear

## How to Use

1. **Open the Website**: Simply open `index.html` in any modern web browser
2. **Switch Language**: Click the language switcher button (🌐) in the top navigation to toggle between Sinhala and English
3. **Navigate**: Use the top navigation menu or scroll through sections
4. **Search**: Use the search box to find specific consciousness states
5. **Filter**: Use the category dropdown to filter by consciousness type
6. **Compare**: Go to the comparison section and select up to 5 states to compare
7. **Mobile**: The site is fully responsive and works on mobile devices
8. **Language Preference**: Your language choice is automatically saved and restored on future visits
