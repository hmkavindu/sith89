## ✅ What to Look For

### Good Response Has:
1. **බි-භාෂා (Bilingual):** සිංහල + English
2. **ත්‍රිපිටක සම්බන්ධතාව:** Sutta references (e.g., "MN 10")
3. **ප්‍රායෝගික යෙදවීම:** Practical application
4. **ව්‍යුහගත:** Structured format
5. **නිවැරදි:** Accurate Buddhist teachings

---

## 🎨 Response Structure

Every answer should have:

```
1. Main Explanation (සිංහල or English based on question)
   └─ Detailed, clear answer

2. Translation (other language)
   └─ Brief summary

3. Tipitaka Reference
   └─ Sutta citations

4. Practical Application
   └─ How to use in life

5. Further Study
   └─ Related topics
```

## 🔍 Troubleshooting

### Issue: Short/Generic Responses
**Solution:** The AI needs context. Ask specific questions.

### Issue: No Sutta References
**Solution:** Restart server to load enhanced prompts.

### Issue: Only English
**Solution:** Ask in Sinhala or set language in interface.

## 💡 Advanced Testing

### Test Conversation Memory:
```
First ask: "චිත්ත කීයක් තිබේද?"
Then ask: "ඒවායේ කාණ්ඩ මොනවාද?"
```
Bot should remember previous context.

### Test Mixed Languages:
```
Ask in English: "What is lobha?"
Then follow-up in Sinhala: "ඒක නැති කරන්නේ කොහොමද?"
```

### Test Deep Knowledge:
```
"Explain the relationship between avijja and tanha in Paticca Samuppada"
```
