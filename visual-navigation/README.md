# 🧘 අභිධර්ම නැවුම් ජාලය (Abhidhamma Knowledge Mesh)

## 🎯 සාරාංශය (Overview)

මෙම ව්‍යුහගත නැවුම් ජාලය සම්පූර්ණ අභිධර්ම දත්ත සම්බන්ධ කරන අන්තර්ක්‍රියාකාරී මෙවලමක් වන අතර භාවිතා කරන්නන්ට චිත්ත, චෛතසික සහ විශ්ලේෂණ අන්තර්ගතයන් අතර සම්බන්ධතාවලට පිවිසීමට ඉඩ සලසයි. සියලුම දත්ත අතර සම්බන්ධතාවලට පිවිසීමෙන් පරිශීලකයින්ට අභිධර්මය ස්වභාවයෙන්ම ඉගෙනීමට හැකි වේ.

**මූලික සංඛ්‍යාලේඛන:**

### 📚 ඉගෙනීමේ මාර්ග (Learning Paths)
1. **මාර්ගය 1**: මුල් පිටුව → මානසික තත්ත්ව → විශ්ලේෂණය → චිත්ත කණ්ඩායම්

- ✅ චිත්ත කණ්ඩායම් අනුව පෙරීම කිරීම (අකුසල්, කුසල්, විපාක, ක්‍රියා)

### Manual Initialization

```javascript
// Initialize graph visualizer
const visualizer = new AbhidhammaGraphVisualizer(
    'containerId',           // HTML element ID
    'graph-data.json'       // Path to data file
);

await visualizer.init();

// Focus on a node
visualizer.focusRaga();
visualizer.focusDwesha();
visualizer.focusMoha();

// Search nodes
visualizer.searchNodes('රාග');

// Reset layout
visualizer.resetLayout();
```

### Integration Class

```javascript
// Graph integration is automatically initialized
// Access via window.graphIntegration

window.graphIntegration.toggleGraph();
window.graphIntegration.focusRaga();
window.graphIntegration.focusDwesha();
window.graphIntegration.focusMoha();
window.graphIntegration.resetLayout();
window.graphIntegration.searchNodes('query');
```

## Customization

### Colors

Edit `graph-data.json` to change node colors:

```json
{
  "id": "raga",
  "color": "#ff6b6b"  // Change this
}
```

### Node Sizes

Modify `graph-visualizer.js` config:

```javascript
this.config = {
    nodeSizes: {
        large: 120,
        medium: 70,
        small: 50
    }
};
```

### Layout

Change layout algorithm in `graph-visualizer.js`:

```javascript
this.cy.layout({
    name: 'breadthfirst',  // Options: breadthfirst, grid, circle, etc.
    roots: '#raga, #dwesha, #moha',
    directed: true
}).run();
```

## Troubleshooting

### Graph not loading

1. Check browser console for errors
2. Verify `graph-data.json` is accessible
3. Ensure Cytoscape.js is loaded
4. Check network tab for failed requests

### Nodes not visible

1. Check node data in `graph-data.json`
2. Verify node IDs match edge sources/targets
3. Check CSS styles aren't hiding nodes

### Navigation not working

1. Verify URLs in node data are correct
2. Check event listeners are attached
3. Test navigation handler function
