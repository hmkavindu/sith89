## 🚀 How to Use

### Quick Start

1. **Start Server:**
   ```bash
   node local-server.js
   ```

2. **Open Browser:**
   ```
   http://localhost:8888
   ```

3. **Open Graph:**
   - Click "දෘශ්‍ය සංචලනය" button in mental states section
   - OR click on Raga/Dwesha/Moha cards

4. **Navigate:**
   - Click nodes to navigate
   - Use search to find nodes
   - Use focus buttons for main nodes

### Standalone Test

Open `visual-navigation/test-graph.html` directly in browser to test graph independently.

## 🐛 Troubleshooting

### Graph not loading
1. Check browser console for errors
2. Verify `graph-data.json` is accessible
3. Ensure Cytoscape.js CDN is accessible
4. Check network tab for failed requests

### Nodes not visible
1. Check node data in `graph-data.json`
2. Verify node IDs match edge sources/targets
3. Check CSS styles aren't hiding nodes

### Navigation not working
1. Verify URLs in node data are correct
2. Check event listeners are attached
3. Test navigation handler function
