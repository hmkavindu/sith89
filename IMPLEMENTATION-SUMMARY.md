## 📋 What Each Level Contains

### Level 1: ඉතා සරල අර්ථය (Simple)
- 4-5 bullet point summary
- Everyday language
- Relatable example

### Level 2: වචන විග්‍රහය (Word Analysis)
- Each term explained
- Etymology and meaning
- Practical examples per word

### Level 3: වර්ගීකරණය (Classification)
- Position in citta system
- Category relationships
- Systematic placement

### Level 4: චෛතසික (Cetasikas)
- Complete list (all present)
- Grouped logically
- Role of each

### Level 5: හේතු (Causes)
- Conditions for arising
- 5-7 thought examples
- Trigger analysis

### Level 6: ගැඹුරු විශ්ලේෂණය (Deep Analysis)
- Technical classification
- Citta process stages
- Hetu analysis

### Level 7: විපාක හා ප්‍රතිකාර (Results & Remedies)
- Bad results (immediate, karmic)
- 5-7 remedies
- Meditation practices

### Level 8: තාක්ෂණික විස්තර (Technical)
- Canonical references
- Pali nomenclature
- Scholarly details
